# Reference reels: analysis and Slow Light takes

Source: the 16 MP4s in `ref/` (not in git). Each take follows `slow-light-design-playbook.md`: 14-26 s, wordless (no voiceover), a few words of on-screen text, one idea, a monotonic counter, a paradox beat, loops, "thought experiment / not to scale" where sizes are compressed, charcoal/navy + cream + gold/teal, red only for markers. We take the topic only, never the footage, assets, text or layout. Built in `tools/<slug>/` with the three.js `renderAt(t)` pipeline (stickman reels follow the New Me Trap character and look).

Facts marked "verify" must be checked against a primary source in the build thread before rendering.
