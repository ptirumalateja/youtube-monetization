# One Came, 2D stickman version: look stills (28 Oct 2026)
Teja asked for a free-flowing 2D stickman instead of the cylinder rig. Canvas 2D: thick round strokes with a thin dark outline and soft glow, front view on the bed edge (like the neuronvisuals bench), dark-warm room with rain, hand-sized phone.
`SHOTS=hook,count,knock,facedown,payoff OUT=output/full node render.cjs`, then `python3 overlay.py output/full output/text`. Uses the global Playwright; no npm install.
