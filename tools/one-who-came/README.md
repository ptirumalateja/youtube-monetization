# 30 People Said "I'm Here For You." One Came: look stills (28 Oct 2026)
Built on the approved Salary dark-warm kit (stage.js, sets.js bedroom, figure.js, sld.js copied from tools/salary-loop-dark; the wardrobe is now a door).
Five 1080x1920 stills: hook, count, knock, facedown, payoff.
`npm i`, then `OUT=output/full SUB=1 SHOTS=hook,count,knock,facedown,payoff node render.cjs`, then `python3 overlay.py output/full output/text`. About 20 s on 4 CPUs.
