# Fast love vs Slow love (ref remake)
Three.js scene (scene.js) rendered headless via Playwright (shoot.js, render.sh <outdir>, 4 workers, ~6 min for 408 frames).
Audio is procedural: music.py (felt piano bed) + fire_sfx.py (crackle/roar following the fire envelopes). Mix: music 0.75 + fire 0.55, loudnorm -15 LUFS.
Layout: cream full-bleed frame, two dark panels (y 262-862, 1004-1604), DAY counter between; all text within y 300-1440.
