## 1. Create the channel (only you can do this; it needs your Google login)
1. youtube.com → profile picture → **Settings** → **Add or manage your channel(s)** → **Create a channel**.
2. Name it (below). This creates a separate **Brand Account**, so Slow Light stays untouched.
3. Claim the handle: try **@vishayamentante**, then `@vishayam.entante`, then `@vishayamentantetelugu`.

## 5. Settings checklist (Studio → Settings)
**Channel → Basic info**
- Country: **India**
- Keywords: as above

**Channel → Advanced settings**
- Audience: **No, set this channel as not made for kids.** This matters: "made for kids" kills Shorts reach.

**Upload defaults → Basic info**
- Title: leave blank
- Description template:
  ```
  👉 [one-line summary]

  📚 Sources: [links]

  🔔 ఇలాంటి మరిన్ని విషయాల కోసం సబ్‌స్క్రైబ్ చేయండి: @vishayamentante
  #VishayamEntante #TeluguShorts
  ```
- Tags: `vishayam entante, telugu facts, telugu shorts, telugu explained`

**Upload defaults → Advanced settings**
- Category: **Education**
- Video language and title/description language: **Telugu**
- License: Standard YouTube License
- Comments: On, "Hold potentially inappropriate comments for review"

**Customization → Branding**
- Upload the picture, banner and watermark (watermark: **Entire video**).

**On every upload:** set "Altered or synthetic content" to **Yes** when the visuals are AI-generated.
